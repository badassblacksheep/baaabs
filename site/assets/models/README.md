# BAAABS 3D models

For logos, render stills, fonts and downloadable reports, see the [site asset directory](../README.md).

| Collection | Where to start |
| --- | --- |
| Deep playa artwork | [Playa model catalog](playa/README.md) with Blender-ready GLBs, editable source and artist references |
| Earl and the raised dance deck | [Roof-attachment assembly](earl-roof-attachment-study.glb), shared by the build workshop and Test Drive |
| Exterior shell revisions | The `baaabs-panelized-v*.glb` files in this directory track successive panel assemblies |
| Structural and transport studies | The `baaabs-subframe-study-*` and `baaabs-panel-mounting-*` files include historical design variants and exploded views |

The active survey-fit GLB embeds the [photographic panel finish](../panel-skin.json). The Blender export packs it. Use the fitted sheet UVs for model derivatives, including the homepage, game and renders. At vehicle scale, mipmaps average the small openings; zooming in resolves the steel webs and punched holes.

See the [interactive build workshop](../../the_build.html) for the current configuration.
